Derivata della funzione \(\boldsymbol{f(x) = \left|x\right|}\)

Consideriamo la funzione \[ f(x)= \left|x\right| \] Calcoliamone la derivata. Per farlo ricordiamo la definizione dell'operazione modulo: \[ \left|x\right| = \begin{cases} x \quad &se\,\,\, x \geq 0 \\\\ -x \quad &se\,\,\, x \lt 0 \end{cases} \] Per calcolare la derivata distinguiamo i casi:

  • se \(\,x \gt 0\,\) la funzione \(\left|x\right| = x\), quindi \[ \left|x\right|' = (x)' = 1 \]

  • se \(\,x \lt 0\,\) la funzione \(\left|x\right| = -x\), quindi \[ \left|x\right|' = (-x)' = -1 \]

Quindi la derivata della funzione \(f(x)= \left|x\right|\) è \[ f'(x) = \begin{cases} -1 \,\, &se\,\,x \lt 0 \\\\ 1 \,\, &se\,\,x \gt 0 \end{cases} \] Osserviamo che esistono due modi più compatti di scrivere la derivata del modulo. \[ f'(x) = \dfrac{\left|x\right|}{x} \qquad \text{oppure} \qquad f'(x) = \dfrac{x}{\left|x\right|} \]








Esercizio

\[ \left(\dfrac{x}{ln(x)}\right)' \]

Soluzione \[\dfrac{ln(x) - 1}{ln^2(x)}\]








Esercizio

\[ \left(\dfrac{x^3}{cos(x)}\right)' \]

Soluzione \[\dfrac{x^2}{cos^2(x)} (3\,cos(x) - x\,sin(x))\]








Esercizio

\[ \left(x + \dfrac{2\,ln(x)}{x^2}\right)' \]

Soluzione \[1 + \dfrac{2\,(1 - 2\,ln(x))}{x^3}\]








Esercizio

\[ \left[\dfrac{x^2 -3}{x^2 + 4}\right]' \]

Soluzione \[\dfrac{14x}{(x^2 + 4)^2}\]









Esercizio

\[ \left[e^x\,(3cos(x) + 2x)\right]' \]

Soluzione \[e^x \, \left(2x - 3sin(x) + 3cos(x) + 2\right)\]
